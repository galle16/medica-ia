# 🏥 MédicaIA — Asistente Clínico con IA

Aplicación de inteligencia artificial para clínicas privadas, desarrollada con **React** y powered by **Claude (Anthropic)**.

## ✨ Funcionalidades
- 🤒 **Modo Paciente** — Evaluación de síntomas, información sobre medicamentos
- 👨‍⚕️ **Modo Médico** — Diagnóstico diferencial, protocolos clínicos
- 🔬 Interpretación de resultados de laboratorio
- 💊 Información farmacológica
- 🔄 Reintento automático ante errores de conexión

## 🚀 Instalación
```bash
npm install
npm run dev
```

## ⚙️ Tecnologías
- React 18 + Vite
- Anthropic Claude API
- Google Fonts (Playfair Display + Source Sans 3)

## ⚠️ Aviso Legal
Este asistente **no reemplaza** la consulta médica profesional. En emergencias llame al **112**.
